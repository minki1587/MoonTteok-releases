# MoonTteok APK 업데이트

이 저장소는 MoonTteok Android 테스트 APK와 업데이트 정보만 공개합니다.
게임 소스 코드는 포함하지 않습니다.

- [APK 다운로드](https://github.com/minki1587/MoonTteok-releases/releases)
- [앱 업데이트 정보](https://raw.githubusercontent.com/minki1587/MoonTteok-releases/main/update.json)

기존 앱에는 자동 업데이트 기능이 없으므로 1.2.0 APK를 처음 한 번 직접 설치해 주세요.
이후에는 앱이 새 버전을 확인하고 Wi-Fi에서 자동 다운로드합니다.
설정 → 앱 업데이트에서 수동 확인하거나 자동 다운로드를 끌 수 있습니다.
설치는 Android 설치 화면에서 직접 승인해야 합니다.

테스트용 preview 채널입니다. 현재 앱과 같은 서명으로만 업데이트할 수 있습니다.
기존 저장 데이터를 유지하려면 앱을 삭제하지 않고 APK를 덮어 설치해 주세요.
